# 🍻 Beníccios Grill & Bar — Website

Website institucional desenvolvido para o **Beníccios Grill & Bar**, com informações sobre o restaurante, cardápio, ofertas, pedidos e contato.

---

## 🌐 Tecnologias Utilizadas

- HTML5  
- CSS3  
- Bootstrap  
- Font Awesome  
- Google Fonts  

---

## 📌 Funcionalidades

- Página inicial com banner e apresentação do bar  
- Seção “Sobre nós”  
- Seção de ofertas e cardápio  
- Área de pedidos com links para WhatsApp e iFood  
- Formulário de contato  
- Mapa integrado do Google Maps  
- Links para redes sociais  
- Layout responsivo  

---
